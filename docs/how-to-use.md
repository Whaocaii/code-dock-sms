## 付款与领取链接

阅读服务说明、创建订单后，按页面显示的金额扫码支付。建议复制完整的付款备注，帮助系统对应订单。

## 获取号码与验证码

1. 先准备好需要验证的第三方页面。
2. 打开领取链接，点击“开始接码”。
3. 获取号码后，自行填写到第三方页面，并请求发送短信。
4. 返回领取页等待验证码，收到后自行使用。

Code Dock 不代登录第三方账号，不需要账号密码。领取页有独立的号码接收倒计时；领取链接的7天有效期不等同于号码接收时限。

系统必须确认上一号码未收到验证码，且达到至少120秒等待时间，才允许换号。每单最多换号10次，能否继续操作以领取页状态为准。

号码可能被第三方拒绝或显示已使用。更换号码不能保证下一号码通过第三方验证，也不承诺号码从未被使用。
