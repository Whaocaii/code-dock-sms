# Code Dock 常见问题

[返回首页](../README.md) · [完整使用指南](how-to-use.md)

## 在线接码是什么？提供账号吗？

这里指使用临时海外手机号接收一次短信验证码。Code Dock 提供号码和短信接收流程，不出售第三方账号，不提供密码，也不代登录账号。

## 默认和自选套餐有什么区别？

默认方案¥9.90/单，为 OpenAI / ChatGPT 自动选国。自选国家或服务为¥29.90/单，选项以购买页当前库存为准。选择自选方案，即使最终选 OpenAI / ChatGPT 加自动选国，也按¥29.90计价。

## 支持哪些服务和国家？

实时目录见[购买页](https://119-28-110-73.sslip.io/shop)。默认方案为 OpenAI / ChatGPT；自选目录只显示当时可售的服务与国家。出现某个平台名称不代表官方合作，也不保证其接受所选号码。

## ChatGPT / OpenAI 手机验证一定能成功吗？

不能保证。第三方是否要求手机号、接受哪类号码，以及账号最终是否通过验证，由第三方规则和账号情况决定。Code Dock 的交付标准是提供本单验证码。

## 手机号是全新或永久独享的吗？

不作此承诺。本服务为临时短信接收，号码历史和第三方使用记录不能完整核验，不提供长期手机号绑定或找回账号的保证。

## 7天指的是号码使用时间吗？

不是。7天是领取链接从生成起的有效期。号码接收时限在领取页单独显示。

## 没收到验证码可以换号吗？

每单最多10次，每次至少等待120秒，并由系统确认上一号码未收到验证码。已收到验证码时不适用未收码换号条件。页面实际状态决定是否允许操作。

## 为什么支付宝付款后没有立即收到链接？

系统需核对真实到账记录；支付平台出账、网络和查账状态可能影响确认速度。请保留原订单页，避免重复付款，必要时联系客服。

## 漏填付款备注怎么办？

在原订单页补填支付宝账单中的“订单号”。请勿填写“商家订单号”。相同付款金额本身不足以确定订单归属。

## 网站购买后，Telegram 一定会发链接吗？

仅从机器人购买入口创建、关联到该私聊的订单，在到账确认后会自动发送领取链接。直接在网站创建的订单应从原订单页领取。

## 收到验证码之后就算交付完成吗？

是。提供验证码后视为交付完成，不保证第三方接受号码或账号最终验证成功。成功交付后不支持无理由退款；重复扣款、未交付等异常由客服核查。

## 这个 GitHub 仓库是短信采购 API 或服务端源码吗？

不是。这里提供公开使用指南、产品事实和只读公开信息工具。托管服务按套餐收费，后端源码及采购 SDK 不包含在仓库中。
